# Danksagung

Ante baut eine einzelne Person, mit Hilfe freier, offener Arbeit anderer. Danke.

## Schriften

Geist (Oberfläche) von Vercel. Uhr-Schriften: Bitcount von Petr van Blokland, Doto von Óliver Lalan, DotGothic16 von Fontworks, Handjet von Rosetta, Workbench und Sixtyfour von Jens Kutilek, Silkscreen von Jason Kottke, Pixelify Sans von Stefie Justprince, VT323 von Peter Hull. Alle unter der SIL Open Font License 1.1.

## Handschrift

Péters Brief an Supporter ist in Caveat von Pablo Impallari gesetzt (SIL Open Font License 1.1).

## Farben

Die Themen Latte, Frappé, Macchiato und Mocha nutzen die Catppuccin-Paletten (MIT-Lizenz).

## Website-Listen

Die Listen der Erwachsenen- und Glücksspielseiten stammen vom The Block List Project (github.com/blocklistproject/Lists) und aus Steven Blacks hosts (github.com/StevenBlack/hosts), beide unter der MIT-Lizenz.

## Icons

Linien-Icons für Ante gezeichnet; das Zahnrad folgt Lucides „settings“-Icon (ISC-Lizenz).

## Design-Werkzeuge

Die animierten Szenen folgen den Stageshow-Richtlinien von Benji Taylor (MIT-Lizenz). Außerdem genutzt: ECC (Everything Claude Code) und Matt Pococks Skills für Planung und Reviews.

## Gebaut mit

Android, Kotlin, Credential Manager und eine WebView; mit Playwright getestet; gemeinsam mit Claude geschrieben.
